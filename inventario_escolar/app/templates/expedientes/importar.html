    • {% endif %}
  • Columnas de documentos: SOL, PRESENTACIÓN, ACEPTACIÓN…
🗜️ Formato ZIP de PDFs

El nombre de cada PDF debe contener el número de control / matrícula del alumno. El sistema detecta el tipo por palabras clave:

  • solicitud / sol → Solicitud
  • presentacion / present → Presentación
  • aceptacion / acept → Aceptación
  • carta / constancia → Carta/Constancia
  • evaluacion / eval → Evaluación
  • liberacion / liber → Liberación

Ejemplo: 20230123_solicitud.pdf → alumno 20230123, documento Solicitud.
